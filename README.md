# /BS//OS

### A Debian-based Linux operating system.

**/BS//OS** is a custom Linux distribution built on Debian, created with the goal of developing a personalized operating system with its own identity, configuration, and experience.

The project uses **Cubic** to customize Debian-based installation media and shape the operating system into its own distribution.

---

## About the Project

/BS//OS is a Linux distribution project focused on customization, system configuration, and the flexibility of the Debian ecosystem.

Rather than being just another application or desktop customization, /BS//OS represents an operating system project: a customized Linux environment built around Debian.

The project has its own name and identity, with room for its own design choices, system configuration, and future development.

## Project Goals

- Build a customized Debian-based Linux distribution.
- Establish a recognizable identity for /BS//OS.
- Customize installation media using Cubic.
- Explore Linux system configuration and customization.
- Maintain the flexibility and foundations of Debian.
- Create an operating system that can develop its own character and direction.

## Technologies

### Debian

[Debian](https://www.debian.org/) provides the foundation for /BS//OS, including its package ecosystem, Linux environment, and established distribution infrastructure.

### Cubic

[Cubic](https://github.com/PJ-Singh-001/Cubic) is used as the ISO customization environment for creating and modifying the distribution's installation media.

## Philosophy

/BS//OS is built around the idea that Linux distributions can be customized to have their own identity and purpose.

Debian provides the foundation, while /BS//OS provides the opportunity to shape that foundation into a distinct operating system.
